# Fallback PR template

Used only when the repo has no pull request template of its own.

```markdown
## Problem

<What problem this PR solves — the why, one short paragraph.>

## What changed

<Summary of the key changes only — the ones a reviewer must understand, not an exhaustive file list.>

## Spec files added

<List any new spec/test files added in this PR. Omit this section entirely if none were added.>
```
