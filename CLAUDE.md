# Personal Skills

This repository holds my personal skills, so they are easy to migrate to a new computer or test with new AI tools.

## Structure

- Each skill lives in its own folder at the repo root.
- Inside each folder there is a `SKILL.md` file describing the skill.

```
skills/
├── some-skill/
│   └── SKILL.md
└── another-skill/
    └── SKILL.md
```
